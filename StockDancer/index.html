주식춤꾼 (StockDancer)

현재가를 춤으로 승화시킨다! 바탕화면 한켠에 띄워두는 투명창 주식 마스코트입니다. 내 종목이 오르면 빨갛게 방방, 내리면 파랗게 시무룩 — 전일 대비 등락률이 클수록 춤이 과감해지고, 장이 닫히면 눈 감고 쿨쿨 잡니다. 국내(KOSPI·KOSDAQ)는 물론 미국·일본 등 해외 종목까지 이름으로 검색해 고를 수 있고, 장이 안 풀려 홧김이 날 땐 클릭해서 두들겨 패면 효과음과 함께 반응합니다. 브라우저가 아닌 Windows 실행 파일이라 내려받아 실행하세요.

⬇ StockDancer.zip 다운로드 (약 15MB)
설치 불필요 · 단일 exe · Windows 10 / 11

실행 방법

  • zip을 풀고 StockDancer.exe 를 실행합니다.
  • SmartScreen 경고가 뜨면 추가 정보 → 실행 (서명 안 된 개인 빌드).
  • 처음 켜면 종목 검색창이 뜹니다 — 삼성전자, 애플처럼 이름을 치거나 6자리 코드를 입력.

조작

  • 종목 버튼(우상단): 종목명·코드 검색 → 후보 클릭. 선택은 자동 저장.
  • 클릭: 캐릭터 때리기(화풀이) — 찌그러지고 튕기며 효과음.
  • 드래그: 창 이동 · ✕ / ESC: 종료.
시세는 네이버 실시간 데이터를 사용합니다(비공식). 재미용 토이예요.
