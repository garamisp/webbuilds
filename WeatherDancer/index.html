날씨춤꾼 (WeatherDancer)

오늘 날씨를 온몸으로 표현한다! 바탕화면 한켠에 띄워두는 투명창 날씨 마스코트입니다. 맑으면 해 아래서 방긋(밤엔 달), 비 오면 먹구름·빗줄기 아래 축 처지고, 눈 오면 고드름 달고 오들오들. 게다가 같은 더위라도 습하면 "찌는 더위"(땀·김 모락모락 헥헥), 건조하면 "타죽는 더위"(머리에 불꽃 이글이글)로 달라집니다. 위치는 IP로 알아서 잡고, 심심하면 클릭해서 두들겨 패기까지. 브라우저가 아닌 Windows 실행 파일이라 내려받아 실행하세요.

⬇ WeatherDancer.zip 다운로드 (약 15MB)
설치 불필요 · 단일 exe · Windows 10 / 11

실행 방법

  • zip을 풀고 WeatherDancer.exe 를 실행합니다.
  • SmartScreen 경고가 뜨면 추가 정보 → 실행 (서명 안 된 개인 빌드).
  • 켜면 현재 위치 날씨를 자동으로 받아옵니다(약 10분마다 갱신).

조작

  • 클릭: 캐릭터 때리기(화풀이) — 찌그러지고 튕기며 효과음.
  • 드래그: 창 이동 · 고정(우상단): 제자리 잠금.
  • 새로고침: 위치·날씨 다시 받기 · ✕ / ESC: 종료.
날씨·위치는 Open-Meteo / ip-api 무키 데이터를 사용합니다. 재미용 토이예요.
